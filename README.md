# Blossom Server for YunoHost

YunoHost packaging for [Blossom Server](https://github.com/hzrd149/blossom-server),
a content-addressed blob storage server for Nostr.

The package runs the upstream Deno service behind YunoHost's NGINX reverse
proxy. Local storage, authenticated uploads/deletes, optional S3 storage, the
admin dashboard, and media optimization can be configured during installation
or later from the YunoHost application configuration panel.

See [the package description](doc/DESCRIPTION.md) for operational notes.
